# Mobile Stock Capture Application

A Windows Forms application for managing mobile phone inventory with SQLite database support.

## Project Overview

This application provides a user-friendly interface for stock management operations.

## Features
- Add new mobile phone records
- Delete records by MobileCode
- Find records by MobileCode
- Automatic SQLite database creation

## Technology Stack
- C# Windows Forms
- SQLite Database
- .NET Framework 4.7.2

## Getting Started

1. Clone the repository
2. Open in Visual Studio
3. Build and run the application
4. Database automatically created on first run
